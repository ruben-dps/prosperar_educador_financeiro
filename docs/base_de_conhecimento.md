# 2. Base de Conhecimento

A base do assistente é organizada de forma modular no diretório `data/`, integrando o contexto completo do cliente:

* **`data/perfil_investidor.json`**: Cadastro do cliente (ex: João Silva, 32 anos, Renda Mensal: R$ 5.000,00, Reserva Atual: R$ 10.000,00) e suas metas estratégicas (Reserva de R$ 15.000,00 e entrada do apartamento de R$ 50.000,00).
* **`data/produtos_financeiros.json`**: Catálogo educativo com opções de renda fixa e fundos (Tesouro Selic, CDB Liquidez Diária, LCI/LCA, Fundo Multimercado e Ações), detalhando prazos, riscos e rentabilidade.
* **`data/transacoes.csv`**: Histórico detalhado de receitas e despesas mensais categorizadas (Aluguel, Supermercado, Lazer, Saúde) para ilustrar o orçamento real.
* **`data/historico_atendimento.csv`**: Registros de atendimentos prévios para manter a continuidade do aprendizado.
